FLARE Public demo · v1.0

Self-hosted BI for multi-business retail groups.

FLARE is the warehouse, dashboard, and analytics platform I designed and built at Nexus Brands Group — replacing legacy reporting across 18 businesses with a single self-hosted stack on Entra SSO, at zero per-seat cost. This is a fully interactive, anonymised public demo running entirely in your browser.

This is a visual clone, not the real product. The real FLARE is a self-hosted Streamlit application running against a private data warehouse with Microsoft Entra SSO and role-based access — built and operated at Nexus Brands Group. This public demo is a static front-end built with vanilla HTML, CSS, and JavaScript: same design language, invented data, no backend. The fictional parent here is Helios Brands Co. with four invented sister brands (Trailcraft, Hearthline, Quill & Press, Velora). Nothing in this demo represents real Nexus data, customers, or warehouse layouts.
