PRIVACY POLICY

LAST UPDATED: MARCH 2026

TL;DR

Nyquist does not collect, store, or transmit any data whatsoever. No analytics. No telemetry. No network connections. Audio is processed in real time for visualization and immediately discarded. We literally cannot see anything you do.

// DATA WE COLLECT

None. Nyquist does not collect any data of any kind. The app makes no network connections, contains no analytics, and has no telemetry. There is no server. There is no account. There is nothing to collect.

// DATA WE DO NOT COLLECT

  • Personal information
  • Device identifiers
  • Usage analytics
  • Audio recordings
  • Crash reports
  • Anything, really

// AUDIO DATA

Audio captured from your system output or microphone is processed in real time for visualization purposes only. Audio data is never recorded, stored, or transmitted. All processing happens locally in memory and is discarded immediately after rendering.

// THIRD-PARTY SERVICES

Nyquist contains no third-party SDKs, analytics frameworks, advertising libraries, or network code. The app is built entirely with Apple system frameworks.

// PERMISSIONS EXPLAINED

SCREEN RECORDING

Required for system audio capture via ScreenCaptureKit. Only the audio stream is used; no screen content is captured or stored.

MICROPHONE

Required only if you select microphone as the audio input source. Audio is processed in real time and immediately discarded. Nothing is recorded.

AUTOMATION

Required for transport controls (play/pause/skip) to communicate with Apple Music or Spotify. No data is read from these applications.

All permissions can be revoked at any time in System Settings → Privacy & Security.

// NOW PLAYING

Track information (title, artist, album) is received via macOS system notifications. This data is displayed in the app interface only and is never stored or transmitted.

// CHILDREN'S PRIVACY

Nyquist does not collect any data from anyone, including children under 13. Since no personal data is collected or transmitted, there is no age-specific data handling required.

// CHANGES TO THIS POLICY

We may update this privacy policy from time to time. Any changes will be reflected on this page with an updated "Last Updated" date. Significant changes will be communicated through the app or App Store update notes.
