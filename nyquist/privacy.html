PRIVACY POLICY

EFFECTIVE: MARCH 2026

DATA COLLECTION

Nyquist does not collect, store, or transmit any personal data. The app operates entirely on your device with no network communication, analytics, or telemetry of any kind.

AUDIO DATA

Audio captured from your system output or microphone is processed in real time for visualization purposes only. Audio data is never recorded, stored, or transmitted. All processing happens locally in memory and is discarded immediately after rendering.

PERMISSIONS

Nyquist may request the following system permissions:

  • Screen Recording — Required for system audio capture via ScreenCaptureKit. Only the audio stream is used; no screen content is captured or stored.
  • Microphone — Required only if you select microphone as the audio input source.
  • Automation — Required for transport controls (play/pause/skip) to communicate with Apple Music or Spotify. No data is read from these applications.

All permissions can be revoked at any time in System Settings → Privacy & Security.

NOW PLAYING

Track information (title, artist, album) is received via macOS system notifications. This data is displayed in the app interface only and is never stored or transmitted.

THIRD PARTIES

Nyquist contains no third-party SDKs, analytics frameworks, advertising libraries, or network code. The app is built entirely with Apple system frameworks.
